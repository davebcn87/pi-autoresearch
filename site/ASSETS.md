# Landing-page asset provenance

- `og-image.webp` is project-original artwork created for the pi-autoresearch landing page. It contains no third-party logo.
- `social-preview-dark.png` is captured from the website's real hero at 2× resolution and downsampled to 1200×630. It uses the production logo and the actual Asciinema-rendered autoresearch UI. The abbreviated commit identifiers and benchmark values are illustrative demo data, not identifiers from a private repository.
- `result-share-card.png` is a project-original visualization of the publicly reported Polaris result in [Shopify Engineering's Autoresearch case study](https://shopify.engineering/autoresearch).
